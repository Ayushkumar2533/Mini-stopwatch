# ⏱️ Mini Stopwatch

A simple and responsive stopwatch built using HTML, CSS, and JavaScript. This project allows users to start, stop, and reset the timer with an easy-to-use interface.

## 🚀 Features

- Start the stopwatch
- Stop/Pause the timer
- Reset the timer to zero
- Clean and user-friendly UI
- Lightweight and beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
